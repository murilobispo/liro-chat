# Liro Chat

Real-time chat, built on WebSockets.

Write a message and it appears instantly for everyone in the room — no refreshing, no
waiting, no "refresh to see new messages". Conversations stay live the way they do in
the apps we already use every day.

Liro Chat is designed to stay out of the way. Rooms are simple, the interface is
clean, and nothing gets between you and the conversation. Send a message, see it
land, keep talking.

Built with React on the frontend, Node.js on the backend, and PostgreSQL to keep your
messages around for later.
